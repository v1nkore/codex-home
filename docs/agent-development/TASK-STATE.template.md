## Правила перехода

- Исполнитель обновляет карточку при смене этапа, появлении блокера и перед передачей задачи другой сессии.
- `Ожидает принятия` допустимо, когда критерии задачи и проверки относятся к текущему HEAD; укажите непроверенное.
- Новый commit после проверки возвращает этап в `проверка`. Старые результаты сохраняются как история, но не подтверждают новый код.
- `Принята` требует решения ответственного человека по указанному commit. `Выпущена` фиксирует отдельный факт релиза.
- Новая сессия сверяет карточку с задачей, PR и HEAD перед работой. При расхождении сначала восстанавливает актуальное состояние.
