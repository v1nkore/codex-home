# Проверка качества агентского ревью

Храните только обезличенные случаи, которые разрешено использовать в рабочей среде. Для воспроизводимости фиксируйте версию требования, commit, версию инструкции ревью и модель. Сам набор содержит как дефекты, которые ревьюер должен найти, так и корректные изменения, которые он должен оставить без ложных замечаний.

| Случай | Вход: задача и diff | Ожидаемая находка или отсутствие замечания | Фактический результат | Решение человека |
| --- | --- | --- | --- | --- |
| Пример: повтор команды после таймаута | Ссылка на разрешённый тестовый артефакт | Риск повторного действия | Заполнить при прогоне | Верно / пропуск / ложное замечание |

После каждого прогона считайте отдельно пропущенные значимые дефекты и ложные замечания. Улучшение инструкции или модели принимается, когда на собственных случаях оно снижает ручную работу и сохраняет обнаружение значимых дефектов. Этот набор помогает оценить ревьюера; он не заменяет тесты продукта и решение ответственного разработчика.
